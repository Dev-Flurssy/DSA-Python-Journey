DATA STRUCTURE

A data structure is a way of organizing, storing, and managing data so that it can be accessed, modified, and processed efficiently.
Data structures help computers store large amounts of data and perform operations quickly.
Think of a data structure as a container that stores data in a specific way.

Examples:
Array
Linked List
Stack
Queue
Tree
Graph
Hash Table

------------------------------------------------------------ 
WHY DATA STRUCTURES ARE IMPORTANT

Data structures help us:

Store data efficiently
Access data quickly
Search data faster
Reduce memory usage
Improve program performance
Solve complex problems effectively

------------------------------------------------------------

No. These are two different classifications.

PRIMITIVE DATA STRUCTURES

Primitive data structures are basic built-in data types provided by a programming language.

Examples:

Integer (int)
Float
Character (char)
Boolean (bool)
list
Set
Dictionary
Tuple

Python examples:
age = 20          # int
height = 1.75     # float
grade = 'A'       # str (character/string)
is_student = True # bool


Characteristics:

Store a single value
Directly supported by the language
Simple and fundamental

------------------------------------------------------------ 
NON-PRIMITIVE DATA STRUCTURES

Non-primitive data structures are built using primitive data types.
They can store multiple values and relationships between values.

Examples:

Array
List
Linked List
Stack
Queue
Tree
Graph
Hash Table

Characteristics:

Store collections of data
More complex
Used to organize information efficiently

------------------------------------------------------------ 
LINEAR DATA STRUCTURES

A linear data structure stores elements sequentially.
Each element is connected to the next element in a single line.

Characteristics:
Easy to traverse
Elements are arranged one after another
Suitable for sequential processing

Examples:
Array
String
Linked List
Stack
Queue

------------------------------------------------------------ 
ARRAY

An array is a collection of elements of the same data type stored in contiguous memory locations.
Each element is accessed using an index.

Example:Array = [10, 20, 30, 40, 50]

Index:
0 → 10
1 → 20
2 → 30
3 → 40
4 → 50

Advantages:
Fast access using index
Easy to implement

Disadvantages:
Fixed size
Costly insertion and deletion

Applications:
Storing marks
Storing temperatures
Matrices and tables

------------------------------------------------------------ 
STRING

A string is a sequence of characters used to represent text.

Example: "HELLO"
Characters: H E L L O

Common Operations:
Accessing characters
Searching text
Comparing strings
Reversing text
Modifying text

Applications:
Text processing
Search engines
Password validation
File names

------------------------------------------------------------ 
LINKED LIST

A linked list is a collection of nodes connected together.
Each node contains:
Data
Reference (Pointer) to the next node

Example: 10 → 20 → 30 → 40

Advantages:
Dynamic size
Easy insertion
Easy deletion

Disadvantages:
Extra memory for pointers
Slower access compared to arrays

Applications:
Music playlists
Browser history
Undo functionality

------------------------------------------------------------ 
STACK

A stack is a linear data structure that follows the LIFO principle.
LIFO = Last In First Out
The last element inserted is the first element removed.

Example:
Stack: Top 30 20 10

Operations:
Push → Add element
Pop → Remove element
Peek/Top → View top element

Applications:
Function calls
Undo operations
Expression evaluation
Browser navigation

Real-life example:
A stack of plates.
The last plate placed on top is removed first.


------------------------------------------------------------ 
QUEUE

A queue is a linear data structure that follows the FIFO principle.
FIFO = First In First Out
The first element inserted is the first element removed.

Example: Front → 10 20 30 40 ← Rear

Operations:
Enqueue → Insert element
Dequeue → Remove element
Front → View first element

Applications:
Printer queue
CPU scheduling
Ticket booking systems
Task processing

Real-life example:
People standing in a line.
The first person in line is served first.

------------------------------------------------------------ 
NON-LINEAR DATA STRUCTURES

A non-linear data structure stores data in a hierarchical or network-like structure.
Elements are not arranged sequentially.

Characteristics:

Multiple relationships between elements
Suitable for complex data representation
Efficient for hierarchical data

Examples:
Hash Table
Tree
Heap
Graph

------------------------------------------------------------ 
HASH TABLE

A hash table stores data as key-value pairs.
A hash function converts a key into an index where the value is stored.

Example:
Name → Age
John → 20
Mary → 25
Alex → 18

Advantages:
Very fast searching
Fast insertion
Fast deletion

Applications:
Dictionaries
Caching
Database indexing
Password lookup

Python Example: 
student["name"] = "Bisola"
Key = "name"
Value = "Bisola"

------------------------------------------------------------ 
TREE

A tree is a hierarchical data structure made of nodes connected by edges.

Important Terms:
Root The first node of the tree.
Parent A node connected above another node.
Child A node connected below a parent.
Leaf Node A node with no children.

Example:
    A
   / \
  B   C
 / \
D   E


Applications:
File systems
Database indexing
Decision trees
Search engines

Advantages:
Fast searching
Hierarchical organization
Efficient insertion and deletion

------------------------------------------------------------
HEAP

A heap is a special tree-based data structure.
It follows the heap property.
Max Heap:
Parent ≥ Children

Example:
    100
   /   \
  80    60
 / \
40  20


Min Heap:
Parent ≤ Children

Applications:
Priority Queues
Heap Sort
Task Scheduling
Dijkstra Algorithm

Advantages:

Fast retrieval of highest or lowest value
Efficient priority management

------------------------------------------------------------ 
GRAPH
A graph is a collection of vertices (nodes) connected by edges.

Example:
A ----- B | | | | C ----- D

Terminology:
Vertex A node in a graph.
Edge A connection between two vertices.

Applications:
Social Networks
Google Maps
Computer Networks
Flight Routes

Common Algorithms:
Breadth First Search (BFS)
Depth First Search (DFS)
Dijkstra Algorithm

------------------------------------------------------------
COMMON OPERATIONS IN DATA STRUCTURES

Operations are actions performed on data stored inside a data structure.

Most data structures support the following operations:
Traversal
Insertion
Deletion
Searching
Sorting
Merging
Updating
Accessing

------------------------------------------------------------
TRAVERSAL

Traversal is the process of visiting each element in a data structure exactly once.

Purpose:
Display data
Process data
Count elements

Example:
Array:[10, 20, 30, 40]

Traversal Output:
10
20
30
40

Applications:
Printing values
Finding sums
Data analysis

------------------------------------------------------------
INSERTION

Insertion is the process of adding a new element into a data structure.

Example:
Before: [10, 20, 40]
Insert: 30
After: [10, 20, 30, 40]

Applications:
Adding a new student
Adding a product
Saving a new record

------------------------------------------------------------
DELETION

Deletion is the process of removing an existing element from a data structure.

Example:
Before: [10, 20, 30, 40]
Delete: 30
After: [10, 20, 40]

Applications:
Removing a user
Cancelling an order
Deleting a file

------------------------------------------------------------
SEARCHING

Searching is the process of finding a specific element in a data structure.

Questions Answered:
Does the element exist?
Where is the element located?

Example:
Array: [10, 20, 30, 40]
Search: 30
Result: Found at Index 2

Applications:
Finding a name
Looking up a phone number
Searching a database

------------------------------------------------------------
SORTING

Sorting is the process of arranging data in a particular order.

Types:
Ascending Order: [10, 20, 30, 40]
Descending Order: [40, 30, 20, 10]

Applications:
Ranking students
Organizing products
Preparing data for searching

------------------------------------------------------------
MERGING

Merging is the process of combining two or more data structures into a single structure.

Example:
Array 1: [10, 20]
Array 2: [30, 40]
Merged Array: [10, 20, 30, 40]

Applications:
Combining records
Merging datasets
Integrating systems

------------------------------------------------------------
UPDATING

Updating is the process of modifying an existing element in a data structure.

Example:
Before: [10, 20, 30]
Update: 20 → 25
After:[10, 25, 30]

Applications:
Updating account balances
Editing profiles
Changing product prices

------------------------------------------------------------
ACCESSING

Accessing is the process of retrieving an element from a data structure.

Example:
Array: [10, 20, 30, 40]
Access Index: 2
Result: 30

Applications:

Reading stored data
Displaying information
Processing records

------------------------------------------------------------
EXAMPLE USING AN ARRAY

Array: [10, 20, 30, 40]

Access: Get element at index 1
Result: 20

Search: Find 30
Result: Found at index 2

Insert: Insert 50
Result: [10, 20, 30, 40, 50]

Delete: Remove 20
Result: [10, 30, 40, 50]

Update: Change 30 to 35
Result: [10, 35, 40, 50]

Sort: Arrange values
Result: [10, 35, 40, 50]

Traverse: Visit all elements
Result: 10, 35, 40, 50
