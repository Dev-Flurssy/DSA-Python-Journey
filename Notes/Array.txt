ARRAY DATA STRUCTURE
------------------------------------------------------------

An Array is a linear data structure that stores a collection of elements in
contiguous (continuous) memory locations.

Formula:
Array = Contiguous Memory + Fixed Size + Indexed Access

Meaning:
• Data is stored in continuous memory locations.
• Elements are accessed using an index.
• All elements are usually of the same data type.

------------------------------------------------------------
CHARACTERISTICS OF AN ARRAY

1. Fixed Size
The size of an array is defined before use and cannot be changed easily.

Example:
arr = [10, 20, 30, 40, 50]
Size = 5

2. Contiguous Memory Allocation
Array elements are stored in adjacent memory locations.

Index :  0    1    2    3    4
Value : 10   20   30   40   50
Because memory locations are continuous, the computer can directly find any element.

3. Direct Access
Elements can be accessed directly using their index.

Example: arr[2]
Output: 30

------------------------------------------------------------
ADVANTAGES OF ARRAYS

1. Fast Access
Since elements are stored in contiguous memory locations, the access time remains almost constant regardless of the array size.

Complexity: Access = O(1)
This is called Constant Time Access.

Example:
arr[0]
arr[500]
arr[1000]

All can be accessed directly without searching.

2. Simple Organization
Arrays are easy to understand and implement.

Benefits:
• Efficient storage
• Sequential organization
• Fast retrieval of data

------------------------------------------------------------
LIMITATIONS OF ARRAYS

1. Costly Insertions
Inserting an element in the middle requires shifting existing elements.

Before Insertion: [10, 20, 30, 40]
Insert 25 at index 2: [10, 20, 25, 30, 40]
Elements 30 and 40 must move one position to the right.

Complexity: Insertion = O(n)

2. Costly Deletions
Deleting an element in the middle also requires shifting elements.

Before Deletion: [10, 20, 30, 40, 50]
Delete 30: [10, 20, 40, 50]
Elements 40 and 50 move one position to the left.

Complexity: Deletion = O(n)

3. Homogeneous Elements
An array stores elements of the same data type.

Examples:
Valid: [10, 20, 30, 40]
Valid: ['A', 'B', 'C']
Not Valid in a Traditional Array: [10, 'A', 3.14]

4. Predetermined Size
The size of an array must be known before it is created.
If more space is needed, a new array must be created.

------------------------------------------------------------
ARRAY AS A MATHEMATICAL MODEL

An array can be represented as a set of pairs: (Index, Value)

Example:
(0, 10)
(1, 20)
(2, 30)
(3, 40)

Where:
Index  → Indicates the position/location.
Value  → Indicates the data stored at that position.

------------------------------------------------------------
FORMAL DEFINITION OF AN ARRAY

An Array is a finite, ordered collection of homogeneous elements stored in contiguous memory locations 
where each element can be accessed directly using an index in constant time O(1).

------------------------------------------------------------
ARRAY AS AN ABSTRACT DATA TYPE (ADT)

ADT Array
Instance:
Create Array(Size)

Pre-condition:
At least one element must exist to perform operations.

Operations:
1. Insert: Add an element to the array.
2. Delete: Remove an element from the array.
3. Access: Retrieve an element using its index.
4. Update: Modify an existing element.
5. Search: Find the location of an element.
6. Traverse: Visit every element in the array.

------------------------------------------------------------
IMPLEMENTATION OF ARRAY USING PYTHON LIST

Python commonly uses lists to implement array-like structures.

Example: arr = [10, 20, 30, 40, 50]

Access:
arr[0]      # 10
arr[3]      # 40

Insert: 
arr.insert(2, 25)

Delete: 
arr.remove(30)

Traverse:
for value in arr:
    print(value)

------------------------------------------------------------
IMPLEMENTATION OF ARRAY USING DICTIONARY

A dictionary can be used to simulate an array by using indices as keys.

Example:
arr = {
    0: 10,
    1: 20,
    2: 30,
    3: 40
}

Access: print(arr[2])
Output: 30

Advantages:
• Easy access using keys
• Dynamic size

Disadvantages:
• Not stored in contiguous memory
• Slower than a true array

------------------------------------------------------------
IMPLEMENTATION OF ARRAY USING ARRAY MODULE

Python provides an array module for creating arrays that store
elements of the same data type.

Import:
from array import *

Create Array:
arr = array('i', [10, 20, 30, 40, 50])

Access: print(arr[2])
Output: 30
Insert: arr.insert(2, 25)
Delete: arr.remove(30)

Advantages:
• Memory efficient
• Stores homogeneous data
• Similar to traditional arrays

Disadvantages:
• Only one data type allowed

------------------------------------------------------------
IMPLEMENTATION OF ARRAY USING NUMPY

NumPy provides a powerful array object for numerical computing.

Import:
import numpy as np

Create Array:
arr = np.array([10, 20, 30, 40, 50])

Access: print(arr[2])
Output: 30
Arithmetic Operations: print(arr + 10)
Output: [20 30 40 50 60]

Advantages:
• Fast computations
• Supports multidimensional arrays
• Efficient memory usage

Disadvantages:
• Requires NumPy installation

------------------------------------------------------------
IMPLEMENTATION OF ARRAY USING CLASS

Arrays can also be implemented using a class.

Example:
class Array:

    def __init__(self):
        self.data = []

    def insert(self, value):
        self.data.append(value)

    def access(self, index):
        if 0 <= index < len(self.data):
            return self.data[index]
        return "Invalid Index"

obj = Array()

obj.insert(10)
obj.insert(20)
obj.insert(30)

print(obj.access(1))
Output: 20

Advantages:
• Supports custom operations
• Encapsulation of data

Disadvantages:
• More complex implementation
• Additional memory overhead

------------------------------------------------------------
COMPARISON OF ARRAY IMPLEMENTATIONS

Dictionary:
• Uses key-value pairs
• Dynamic size
• Not a true array

Array Module:
• Homogeneous elements
• Memory efficient
• Close to traditional arrays

NumPy Array:
• High performance
• Mathematical operations
• Supports multidimensional arrays

Class-Based Array:
• User-defined implementation
• Flexible
• Used for learning data structures
